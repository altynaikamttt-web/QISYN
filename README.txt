QISYN — оқу мақсатындағы серверлік прототип.

1) Python 3.10+ орнатыңыз.
2) Терминалда осы бумаға өтіңіз.
3) Құпиясөз орнатыңыз (кемінде 12 таңба):
   Windows PowerShell: $env:QISYN_ADMIN_PASSWORD='Өзіңіздің_күрделі_құпиясөзіңіз'
   Linux/macOS: export QISYN_ADMIN_PASSWORD='Өзіңіздің_күрделі_құпиясөзіңіз'
4) python server.py
5) http://localhost:8000 ашыңыз.
   Мұғалім логині: teacher; құпиясөз — 3-қадамда орнатқаныңыз.
6) Мұғалім кабинетінен оқушы логиндерін жасаңыз.

МАҢЫЗДЫ: Бұл жергілікті прототип. Интернетке тікелей жарияламаңыз.
Онлайн орналастыруға дейін HTTPS, тұрақты серверлік сессиялар, CSRF қорғанысы,
кіру әрекеттеріне шектеу, қауіпсіз резервтік көшіру, мұғалімнің құпиясөзін ауыстыру,
жеке деректерді қорғау және қауіпсіздік аудиті қажет.
Сессиялар сервер қайта іске қосылғанда жойылады; оқушылар мен нәтижелер SQLite-да сақталады.
Оқушылардың нақты аты-жөнін енгізбей, кодталған логиндер қолданған жөн.
